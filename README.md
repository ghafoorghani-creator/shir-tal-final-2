# شعر و تال غفور

وب‌اپلیکیشن مستقل برای مدیریت شعر، راگ، تال و فایل‌های صوتی/تصویری و تمرین موسیقی.

## اجرا روی GitHub Pages
1. همه فایل‌های این پوشه را در ریشه یک repository قرار دهید.
2. در GitHub → Settings → Pages، منبع انتشار را روی branch موردنظر و `/root` تنظیم کنید.
3. برنامه با مسیرهای نسبی ساخته شده و برای repository pages نیز قابل استفاده است.
4. Service Worker فقط روی HTTPS ثبت می‌شود.

## ذخیره‌سازی
- داده‌های اصلی و Blob فایل‌های رسانه‌ای در IndexedDB ذخیره می‌شوند.
- تنظیمات کوچک در localStorage هستند.
- ظرفیت IndexedDB وابسته به مرورگر و فضای دستگاه است؛ رسانه‌های بسیار حجیم ممکن است محدودیت ایجاد کنند.

## Apple Notes
دسترسی مستقیم به پایگاه داده Apple Notes توسط یک وب‌اپ معمولی ممکن نیست. از Share/Copy-Paste یا Import فایل TXT/Markdown/CSV/JSON استفاده کنید.

## پشتیبان
- JSON: ساختار، ارتباط‌ها و تنظیمات.
- Markdown: متن شعرها.
- رسانه‌ها: خروجی فایل‌های رسانه‌ای به‌صورت جداگانه.
JSON عمداً Blob رسانه‌ای را داخل خود قرار نمی‌دهد تا فایل پشتیبان ساختاری بیش از حد حجیم نشود.

## محدودیت iPhone
پخش HTML5 و Media Session تا حد توان مرورگر استفاده شده است، اما یک PWA/HTML معمولی نمی‌تواند تضمین کند که صدا بعد از Force Quit یا کشته‌شدن کامل فرایند iOS ادامه پیدا کند.

## تست رسانه
برنامه نوع MIME، خطای بارگذاری و متادیتای مدت را هنگام افزودن فایل بررسی می‌کند. پخش واقعی MP3 به فایل MP3 و محیط مرورگر نیاز دارد؛ این بسته بدون فایل صوتی شخص ثالث منتشر شده است.
